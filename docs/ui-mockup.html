Dễ theo dõi

Thẻ trắng bo góc, bóng nhẹ; mỗi màn hình đọc từ trên xuống: bối cảnh → kết quả → gợi ý → hành động. Màu trạng thái nhất quán: xanh lá = tốt/KO, vàng = trung bình, đỏ = rủi ro.

Chữ & mở rộng

Nunito cho mọi chữ, tối thiểu 11–12px. Mỗi tab là module độc lập; thêm tab mới chỉ cần đăng ký vào thanh tab. Có sẵn light/dark mode.
